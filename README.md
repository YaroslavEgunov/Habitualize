# Habitualize — Кроссплатформенное приложение для формирования полезных привычек с элементами геймификации

**Habitualize** — это современный кроссплатформенный программный комплекс, разработанный для эффективного планирования времени, внедрения полезных привычек, мониторинга эмоционального состояния и повышения личной эффективности пользователей. 

Проект объединяет в себе комплексный трекинг, игровые механики (уровни, квесты, достижения) и инструменты социального взаимодействия.

---

## ✨ Ключевые модули и возможности

### 🎮 Геймификация и Прогрессия
- **Система уровней и опыта:** Окно прогрессии на главном экране отображает текущий уровень пользователя и шкалу опыта. При выполнении задач уровень повышается с выводом нативного уведомления.
- **Ежедневные задания (Quests):** Динамические квесты, мотивирующие пользователя заходить в приложение каждый день.
- **Система достижений (Achievements):** Модуль содержит 13 уникальных достижений (например, *Beginner Reader*, *Reading Lover*, *Book Worm*, *Staying Healthy*). При выполнении условий триггерится алгоритм разблокировки, выдается push-уведомление, а в профиле обновляется иконка награды.

### 📅 Трекинг и Планирование
- **Категоризированные привычки:** Логика создания, редактирования и удаления привычек разделена на 4 базовых класса (наследуются от `HabitTemplate`):
  - 🌿 **Plants (Gardening):** Полив растений (выполнение засчитывается раз в два дня).
  - 🏋️‍♂️ **Sport (Training):** Контроль веса (необходимо указать целевой и текущий вес).
  - 📚 **Books (Reading):** Чтение книг с фиксацией прочитанных страниц.
  - 📝 **Custom Habits:** Пользовательские привычки со списками подзадач.
- **Интерактивный календарь:** Реализован на базе `Plugin.Maui.Calendar`. Дни с запланированными привычками помечаются точками; при выборе даты отображается детальный список задач на день.
- **30-дневные планы:** Модуль готовых программ (например, *"Drink water"*, *"Morning exercises"*) с автоматическим открытием новых дней в полночь и фиксацией промежуточных результатов.

### 📊 Аналитика и Психологическая поддержка
- **Дневник настроения (Mood Diary):** Позволяет фиксировать эмоциональное состояние (Отличное, Хорошее, Нейтральное, Плохое, Ужасное). Каждая запись содержит заголовок, описание, дату и цветовую индикацию.
- **Визуализация статистики:** Модуль на базе `Syncfusion.Maui.Charts` строит интерактивные круговые диаграммы и графики, отображая общее количество выполненных привычек и максимальные серии дней (streaks) по каждой категории.

### 📱 Мобильная инфраструктура и Соц. функции
- **Android-виджет рабочего стола:** Информационный виджет (разработан с использованием `CommunityToolkit.Maui`), обновляющий интерфейс через `BroadcastReceiver` и сохраняющий кэш в `SharedPreferences`. Показывает расписание на 7 дней.
- **Социальная сеть и Real-time чат:** Система добавления в друзья с push-уведомлениями. Встроен мессенджер реального времени на базе **ASP.NET Core SignalR** (WebSockets) для общения с друзьями.
- **Обучающий маскот:** Виртуальный помощник, помогающий новым пользователям освоить интерфейс при первом запуске (состояние сохраняется через `Preferences` во флаг `TutorialShown`).

## 🛠 Технологический стек и Архитектура

### Архитектурный паттерн
Приложение спроектировано по строгому шаблону **MVVM (Model-View-ViewModel)** с использованием пакета `CommunityToolkit.Mvvm`, что обеспечивает полное разделение визуального интерфейса (XAML) и бизнес-логики (C#), упрощая тестирование и поддержку кода.

### Клиентская часть (Mobile / Desktop)
- **Фреймворк:** .NET MAUI (Multi-platform App UI) — единый код для Android, iOS, macOS и Windows.
- **Оптимизация производительности:** Переход на **одностраничную модель (SPA)** снизил время загрузки XAML-компонентов и конструкторов классов более чем в 2 раза, оптимизировав нагрузку на CPU в режиме простоя.

### Облачные сервисы и Backend
- **Firebase Authentication:** Безопасная авторизация по Email/паролю. Пароли автоматически хэшируются на стороне сервера по алгоритму **SCRYPT**.
- **Firebase Realtime Database:** NoSQL база данных, хранящая информацию в формате JSON-дерева. Из-за ограничений полиморфизма JSON в базу пишется строковое поле `Type`, по которому данные корректно десериализуются в соответствующие классы (`Gardening`, `Reading`, `Training`).
- **Сетевое взаимодействие:** Собственный REST Web-API (`Habitualize.API`) с прослойкой `Habitualize.Core`. Доступ к данным защищен протоколом OAuth 2.0 (**Bearer token**).

## 📦 Использованные NuGet-пакеты

1. `CommunityToolkit.Maui` — кастомные контейнеры (для маскота), анимации и логика виджета.
2. `CommunityToolkit.Mvvm` — инструменты для реализации паттерна MVVM (ObservableProperty, RelayCommand).
3. `FirebaseAuthentication.net` — интеграция с сервисом авторизации Firebase.
4. `FirebaseDatabase.net` — реактивное взаимодействие с Realtime Database.
5. `Plugin.Maui.Calendar` — компонент встроенного календаря привычек.
6. `Syncfusion.Maui.Charts` — построение графиков статистики и круговых диаграмм.
7. `Microsoft.AspNetCore.SignalR.Client` — клиентская библиотека для работы real-time чата.

## 💻 Развертывание и запуск проекта

### Системные требования
- **IDE:** Visual Studio 2022 (с установленной рабочей нагрузкой *.NET Multi-platform App UI development*).
- **SDK:** .NET SDK 8.0 или новее.
- **Аккаунт Firebase:** Для подключения базы данных и аутентификации.

### Инструкция по настройке

1. **Клонирование проекта:**
   ```bash
   git clone https://github.com
   cd habitualize
   ```

2. **Настройка конфигурации облака:**
   В проекте в файле инициализации сервисов базы данных (например, `SaveAndLoad.cs` или файле конфигурации) укажите URL-ссылку на вашу базу данных Firebase Realtime Database:
   ```csharp
   new FirebaseClient("https://firebaseio.com");
   ```

3. **Настройка Web API:**
   В файле `appsettings.json` для серверной части `Habitualize.API` укажите параметры генерации JWT-токенов для авторизации по Bearer-токену.

4. **Запуск:**
   Выберите целевую платформу (Windows Machine или эмулятор Android/iOS) в Visual Studio и нажмите **F5 (Start Debugging)**.
